# Code of conduct

This repository exists so that people can do something for the first time in
front of other people. That only works if it is safe to be a beginner here.

## What we expect

- **Assume the other person is new.** Because they usually are.
- **No mocking anybody's question.** There are no stupid questions in this
  repository. There are questions that have been asked before, and the
  answer to those is a link, kindly given.
- **Nothing in your file that you would not say out loud in the lecture
  theatre.** Your file is public forever, under your real username. No
  insults, no slurs, no targeting anybody, no personal details about other
  people — theirs or, honestly, your own.
- **Do not add anybody but yourself.** One file, your username, your words.
- **Help if you can.** If somebody's check is red and you know why, say so
  in a comment. That is a contribution too.

## What is not acceptable

Harassment, discrimination, or abuse of any kind — including on the basis of
gender, gender identity, sexuality, disability, appearance, body size, race,
caste, religion, or nationality. Sexual language or imagery. Publishing
somebody's private information. Deliberately wasting reviewers' time.

## If something goes wrong

Tell Hemant Singh Rao: **hemantsingh.rao001@gmail.com**

You can also report anything privately to GitHub itself at
[github.com/contact/report-abuse](https://github.com/contact/report-abuse).

Reports are taken seriously and handled discreetly. You will not be made to
argue your case in public.

## What happens then

Depending on what happened: a quiet word, an edit, a closed pull request, or
a block from the repository. Content that breaks these rules is removed
without discussion.

## Scope

This applies to everything in this repository — pull requests, issues,
comments, file contents — and to the session it was built for.
